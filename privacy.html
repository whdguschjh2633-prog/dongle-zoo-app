Privacy Policy — Dongle Zoo Publisher

Last updated: 2026-10-10

What the app is

Dongle Zoo Publisher is a private tool run on the creator's own computer. Its only user is the creator of the "동글동글 동물원" channel, who uses it to upload their own videos to their own YouTube, TikTok and Instagram accounts.

Data we access

  • Account identifiers needed to post: YouTube channel ID and name, TikTok open_id and display name, Instagram account ID and username.
  • OAuth access and refresh tokens granted by the account owner.
  • Upload results returned by each platform (video or post IDs, processing status).

We do not collect data about viewers, followers or any other person.

How data is stored and used

Tokens and identifiers are stored only in a local file on the creator's computer. They are used only to upload videos and set titles, descriptions and privacy settings that the creator has approved. Nothing is sold, shared with third parties, or used for advertising.

Deleting data

The creator can revoke access at any time from each platform's account settings (Google Account → Third-party access, TikTok → Settings → Security → Apps, Facebook/Instagram → Apps and websites). Deleting the local token file removes all stored data.
